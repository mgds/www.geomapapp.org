Dear GeoMapApp community,

We are pleased to announce a new release of GeoMapApp, version 3.7.8.

This release includes enhanced functionality and several bug fixes.

Faster, more informative grid imports
A new progress bar provides clear feedback when importing large grids; an improved GeoTIFF workflow makes the import of GeoTIFF grids more efficient.

Image Rotation
Imported image overlays can now be rotated to a user-defined angle, providing greater flexibility for positioning and aligning imagery.

Faster access to seismic reflection data
New caching capabilities in the Digital Seismic Reflection Profiles portal significantly reduce the portal loading time and improve access to portal content.

New Shapefile and KML Export options
Built-in and user-imported tabular data sets may now be exported to Shapefile and KML formats, making it easier to move data between GeoMapApp and other geospatial applications.

Improved Shapefile Styling
Expanded controls provide greater flexibility in defining the color and appearance of Shapefile outlines.

More flexible Layer Manager
The Layer Manager window may now be resized, making it easier to view and work with layers that have long names.

More details about the release may be found here.
